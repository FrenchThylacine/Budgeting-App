# Non-Negotiable Business Rules

These rules must **never** be violated.

### Rule 1

A value of **0** is valid.

Never interpret 0 as missing data.

---

### Rule 2

Missing historical values remain missing.

Never silently replace missing values with zero.

---

### Rule 3

Historical snapshots are immutable.

History must never change automatically.

---

### Rule 4

Recurring expense calculations must remain mathematically correct.

---

### Rule 5

Currency conversion affects presentation only.

Stored financial values must remain consistent.

---

### Rule 6

Budget approvals are permanent historical records.

Never overwrite them automatically.

---

### Rule 7

Financial correctness is more important than UI.

Always.
