---

# Ultimate Goal

The application should eventually feel like:

Apple designed it.

Linear polished it.

Copilot Money inspired it.

Monarch organised it.

Revolut visualised it.

Notion simplified it.

The result should be an application that users genuinely enjoy opening every day.

---

# Final Principle

Never add a feature simply because it is impressive.

Every feature should answer one question:

"Does this genuinely help the user understand and manage their finances better?"

If the answer is no,

don't build it.
